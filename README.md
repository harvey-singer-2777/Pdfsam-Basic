## 📖 About

PDFsam Basic is an open source PDF manipulation tool maintained by the PDFsam project, built in Java and packaged for Windows desktops. It handles the routine operations people need most often: merging several documents into one file, splitting a large file into smaller pieces, rotating or reordering pages, extracting selected pages, and mixing alternating pages from two documents. Recent builds focus on smoother large file handling and an updated interface for high DPI displays.

If you came looking for a PDFsam Basic download for Windows 10 or 11, this page lists the current system requirements, install steps and common troubleshooting fixes.

**Good for:** students assembling reports · office workers merging scanned forms · archivists splitting large document sets · anyone reorganizing page order · small teams preparing print ready files · users who prefer offline desktop tools.

## 🛠️ Troubleshooting

| Problem | Solution |
|---|---|
| Setup file blocked by SmartScreen | Click **More info**, then **Run anyway**. |
| Installer window does not appear | Check the taskbar for a hidden window, or run the setup file again as administrator. |
| Application closes on startup | Confirm Java runtime is present or reinstall the bundled runtime with the setup file. |
| Large PDF takes very long to load | Close other memory heavy applications and retry with the document on a local drive. |
| Merged output missing pages | Verify source files are not password protected and recheck the selected page ranges. |
| Interface text looks blurry | Set display scaling to 100 percent or update the graphics driver. |
| Split output files land in wrong folder | Choose an output directory explicitly instead of using the default save location. |
